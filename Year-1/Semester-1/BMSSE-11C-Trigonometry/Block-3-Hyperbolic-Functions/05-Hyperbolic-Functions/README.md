# Unit 5 — Hyperbolic Functions

## Topics
- Definitions of hyperbolic functions
- Relation between circular and hyperbolic functions
- Formulas in hyperbolic functions

## Key Definitions
- sinh x = (eˣ - e⁻ˣ)/2
- cosh x = (eˣ + e⁻ˣ)/2
- tanh x = sinh x/cosh x = (eˣ - e⁻ˣ)/(eˣ + e⁻ˣ)
- coth x = cosh x/sinh x = (eˣ + e⁻ˣ)/(eˣ - e⁻ˣ)
- sech x = 1/cosh x = 2/(eˣ + e⁻ˣ)
- cosech x = 1/sinh x = 2/(eˣ - e⁻ˣ)

## Important Identities
- cosh²x - sinh²x = 1 (fundamental identity)
- 1 - tanh²x = sech²x
- coth²x - 1 = cosech²x

## Relations with Circular Functions
- sinh(ix) = i sin x
- cosh(ix) = cos x
- tanh(ix) = i tan x
- sin(ix) = i sinh x
- cos(ix) = cosh x
- tan(ix) = i tanh x

## Osborn's Rule
Replace circular with hyperbolic: sin → sinh, cos → cosh
**BUT** change sign wherever there is a product of two sines

Examples:
- sin²x + cos²x = 1 becomes cosh²x - sinh²x = 1
- cos(A+B) = cos A cos B - sin A sin B becomes cosh(A+B) = cosh A cosh B + sinh A sinh B

## Addition Formulas
- sinh(A ± B) = sinh A cosh B ± cosh A sinh B
- cosh(A ± B) = cosh A cosh B ± sinh A sinh B
- tanh(A ± B) = (tanh A ± tanh B)/(1 ± tanh A tanh B)

## Double Angle Formulas
- sinh 2x = 2 sinh x cosh x
- cosh 2x = cosh²x + sinh²x = 2cosh²x - 1 = 1 + 2sinh²x
- tanh 2x = 2tanh x/(1 + tanh²x)
