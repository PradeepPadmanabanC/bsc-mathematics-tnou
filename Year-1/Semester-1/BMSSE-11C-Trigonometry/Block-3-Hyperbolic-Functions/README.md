## Key Concepts
- Definition: sinh x = (eˣ - e⁻ˣ)/2, cosh x = (eˣ + e⁻ˣ)/2
- Fundamental identity: cosh²x - sinh²x = 1
- Osborn's rule for converting circular to hyperbolic formulas
- Inverse functions and their logarithmic forms
