# Unit 4 — Trigonometric Function Expansions-II

## Topics
- Expansions of sin x, cos x, tan x in terms of x
- Sum of roots of trigonometric equations
- Formation of equation with trigonometric roots

## Key Formulas

### Maclaurin Series
- sin x = x - x³/3! + x⁵/5! - x⁷/7! + ... = Σ(-1)ⁿ x^(2n+1)/(2n+1)!
- cos x = 1 - x²/2! + x⁴/4! - x⁶/6! + ... = Σ(-1)ⁿ x^(2n)/(2n)!
- tan x = x + x³/3 + 2x⁵/15 + 17x⁷/315 + ...

### Roots of Trigonometric Equations

#### Sum of Roots
For tan nθ = tan α, if roots are θ₁, θ₂, ..., θₙ:
- Sum of roots: θ₁ + θ₂ + ... + θₙ
- Product of roots
- Using Vieta's formulas

#### Formation of Equations
Given roots like tan α, tan β, tan γ, form equation:
- Use symmetric functions
- Apply sum and product formulas
- Express coefficients in terms of elementary symmetric functions

## Important Techniques
1. Maclaurin series derivation
2. Converting trigonometric equations to polynomial form
3. Using tan x/1 to create polynomial equations
4. Applying Vieta's formulas to trigonometric roots
