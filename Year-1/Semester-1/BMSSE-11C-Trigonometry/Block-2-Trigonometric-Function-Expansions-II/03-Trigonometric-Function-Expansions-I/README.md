# Unit 3 — Trigonometric Function Expansions-I

## Topics
- Expansions of sin nθ, cos nθ, tan nθ
- Expansions of tan(θ₁ + θ₂ + ... + θₙ)

## Key Formulas

### Multiple Angle Expansions
- tan 2θ = 2tan θ/(1 - tan²θ)
- tan 3θ = (3tan θ - tan³θ)/(1 - 3tan²θ)
- tan nθ in terms of tan θ

### Tangent Addition Formula
- tan(A + B) = (tan A + tan B)/(1 - tan A tan B)
- tan(A + B + C) = (tan A + tan B + tan C - tan A tan B tan C)/(1 - tan A tan B - tan B tan C - tan C tan A)
- General formula for tan(θ₁ + θ₂ + ... + θₙ)

### Pattern for tan(sum)
Numerator: sum of all products of tangents taken odd at a time
Denominator: 1 - sum of all products of tangents taken even at a time
